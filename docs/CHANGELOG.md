# Changelog

Changelog **client** : ce qui a changé pour les utilisateurs, regroupé par période, en français.
Une section par période, la plus récente en haut ; l'ancre `last-commit` marque le dernier commit
couvert, pour reprendre la section suivante là où celle-ci s'arrête. Format d'une section :

```markdown
## Du 1er au 15 janvier 2026
<!-- last-commit: <sha> -->

### Nouveautés
- **Titre court** : une phrase sur le bénéfice utilisateur.

### Améliorations
- …

### Corrections
- …
```
